About Dropwise

Dropwise is a web tool for writing eye drop plans after eye surgery and for glaucoma. It prints a one-page sheet and makes a phone page with reminders, in eight languages.

Open the builder Example phone page

Who it helps

Eye drop routines are hard to follow when the instructions are in a second language, the print is small, or the schedule changes every week.

Patients who prefer another language

Sheets, phone pages, alarms and spoken instructions in eight languages.

Accessibility

Large type, cap colours written as words, pictures for each step, and adjustable text size on the phone.

Long or complex tapers

Trabeculectomy, DMEK and other plans with hourly drops or steroids that continue until the surgeon stops them.

People with glaucoma

Daily drops with no end date, shown with when to use each one and its possible side effects.

Surgery on both eyes

Separate courses for each eye, each starting on its own day.

Family members and caregivers

The phone page can be shared with whoever helps with the drops.

Clinics without a shared chart

A patient code lets another clinic using Dropwise load the same plan.

How it works

The clinician fills in one form. The patient gets a sheet and a phone page with the same plan.

  1. Build the plan

    Choose the surgery or glaucoma, the eye and the dates. Adjust the drops, or load a saved protocol.

  2. Print one sheet

    Double-sided, in the patient's language. The front has the schedule and a QR code. The back has instructions, precautions and warning signs.

  3. Scan the QR code

    The phone shows what to use next, walks through each bottle and can add an alarm for every dose. See an example

For clinicians

  • Surgery presetsCataract, trabeculectomy, vitrectomy, DMEK, PRK and LASIK, based on published regimens. Sources are linked in the builder.
  • GlaucomaPick from prostaglandins, beta-blockers, alpha agonists, carbonic anhydrase inhibitors, pilocarpine, netarsudil and fixed combinations. No taper: each drop has an eye and how often.
  • New surgeriesName your own surgery, set its drops and save it to the Surgery list.
  • Taper editorEach step shows as a block sized by doses per day, with buttons for common tapers such as 4→3→2→1 weekly.
  • Drug searchFind a drop by generic name, brand, type or cap colour. Any other drop can be added by name.
  • Usual drops and appointmentsMark the patient's existing drops as keep or stop, and add follow-up visits.
  • Saved protocolsExport and import them to share within a clinic.
  • Clinic settingsClinic name, phone and logo, saved on the computer and printed on every sheet.
  • Chart note and patient codesA plain-English summary to copy into the EMR, and an optional 8-character code for the plan.

For patients

  • Printed sheetMorning, noon, evening and bedtime columns. Each bottle is named by cap colour, generic name and brand, with the order to use them.
  • What to use nowThe phone shows the next drops and today's list. Each dose can be ticked off.
  • Step by stepOne bottle at a time, with a 5-minute timer and a chime before the next one.
  • AlarmsCalendar alarms for each dose that name the cap colour, drug and eye, plus a reminder the day before each appointment.
  • Read aloudInstructions spoken in the patient's language.
  • Text sizeChosen the first time the page opens and changeable any time.
  • ProgressA calendar of the days when all drops were done.
  • Instructions and safetyPictures for each step, what to do after a missed dose, precautions and warning signs. Glaucoma sheets also list possible side effects.

Privacy

Dropwise is built so that it doesn't need to store patient information.

No accountsNobody signs up or logs in.
No patient names storedThe name prints on paper only. It is not in the QR code, link or patient code.
The plan is in the linkThe QR code contains the schedule itself, so no server is needed to open it.
Progress stays on the phoneTicked doses and settings are saved only on the patient's device.
Patient codes are optionalWhen used, they store only the drop plan and expire after two years.
Clinic details stay localName, phone and logo are saved in the clinic's browser.

FAQ

Can I use my own protocol instead of the presets?

Yes. Every drop and taper step can be edited, and the result can be saved as a protocol or as a new surgery.

How is the glaucoma sheet different?

There is no taper or end date. The sheet shows one "every day" card with the time of day for each drop, then a card per bottle with which eye, how often and possible side effects. The back has glaucoma precautions and warning signs.

What if the patient's bottle has a different cap colour?

Change the cap colour for that drop in the builder. The sheet, phone page and alarms also remind patients to check the drug name on the label.

Does the patient need to install an app?

No. The QR code opens a web page. It can be added to the home screen and works without internet once opened.

How do the alarms work?

The phone page creates a calendar file, and the phone's calendar sounds an alarm at each dose time. If the plan changes, the patient is told to delete the old alarms before adding new ones.

Can another clinic see the plan?

Only if the patient shares their link or code. A clinic that uses Dropwise can enter the code to load the plan.

Does it replace the doctor's instructions?

No. The presets are starting points. The sheet shows whatever the prescribing doctor sets, and patients should follow their own doctor's instructions.
